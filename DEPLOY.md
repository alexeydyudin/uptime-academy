# Деплой MVP бесплатно: Render + Neon + cron-job.org

Один сервис на Render отдаёт и игру, и API. База живёт в Neon (бесплатно и бессрочно). cron-job.org раз в 14 минут будит сервис и запускает напоминания утки.

Займёт минут 15. Карта нигде не нужна.

## 1. GitHub

Создай пустой репозиторий (можно приватный) и залей проект:

```bash
cd uptime-academy
git remote add origin git@github.com:<твой-логин>/uptime-academy.git
git push -u origin main
```

Коммит уже сделан, остаётся только `remote add` и `push`.

## 2. База в Neon

1. Зарегистрируйся на neon.com (можно через GitHub).
2. Create project → регион **AWS Europe Central (Frankfurt)**, рядом с Render.
3. На странице проекта нажми **Connect** и скопируй строку подключения. Она выглядит так:
   `postgresql://neondb_owner:...@ep-xxx.eu-central-1.aws.neon.tech/neondb?sslmode=require`

Таблицы создавать не нужно: API применит миграции при первом старте.

## 3. Сервис в Render

1. Зарегистрируйся на render.com через GitHub и дай доступ к репозиторию.
2. **New → Blueprint** → выбери репозиторий. Render прочитает `render.yaml`.
3. Он попросит одно значение: `DATABASE_URL`. Вставь строку из Neon.
4. **Apply**. Первая сборка идёт 3–5 минут.
5. Когда статус станет Live, открой адрес вида `https://uptime-academy-xxxx.onrender.com`.

`JWT_SECRET` и `CRON_SECRET` Render сгенерирует сам. VAPID-ключи для push API создаст при первом запуске и сохранит в базе.

## 4. Будильник в cron-job.org

Бесплатный сервис на Render засыпает через 15 минут без трафика, а спящий сервис не отправит напоминание.

1. В Render: сервис → **Environment** → скопируй значение `CRON_SECRET`.
2. Зарегистрируйся на cron-job.org → **Create cronjob**:
   - URL: `https://<твой-адрес>.onrender.com/api/jobs/tick?key=<CRON_SECRET>`
   - Schedule: каждые **14 минут**
3. Сохрани и нажми **Test run**. В ответе должно быть `{"ok":true,...}`.

Так сервис почти не спит: 31 день × 24 часа = 744 часа, это укладывается в лимит Render в 750 часов в месяц. Держи на этом аккаунте Render только этот сервис.

## 5. Проверка

- Открой сайт, пройди урок, зарегистрируйся, открой на телефоне и войди: прогресс должен подтянуться.
- Аккаунт → «Включить уведомления утки» → «Тест». На Android и десктопе push придёт сразу. На iPhone сначала «Поделиться → На экран „Домой“», открыть оттуда, и только потом включать уведомления.

## Ограничения бесплатной схемы

- Если сервис всё-таки уснул, первое открытие займёт около минуты.
- Neon: 1 ГБ на проект и лимит часов вычислений. Для MVP с сотнями игроков хватит с запасом.
- Render Hobby: 5 ГБ исходящего трафика в месяц. Игра весит около 60 КБ в gzip, этого хватит на десятки тысяч заходов.
- Полноценных бэкапов на бесплатных планах не рассчитывай. Перед тем как звать много людей, настрой регулярный `pg_dump` (например GitHub Action раз в сутки) или переходи на платный план.

## Админ-доступ

Render → сервис → **Environment** → Add variable: `ADMIN_EMAILS` = твоя почта (несколько через запятую). Для этих аккаунтов открыты все уроки и не тратятся жизни. После сохранения Render перезапустит сервис, в игре обнови страницу.

## Обновления

`git push` в main → Render сам пересоберёт и перезапустит сервис.
